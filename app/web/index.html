DEVELOPER GUIDE

使用文档

从健康检查到异步任务的完整接入路径。

打开完整 API 文档
01 · HEALTH

先检查服务状态

健康接口无需 API Key，会返回解析组件与数据库可用状态。

curl http://localhost:8080/health
02 · SYNC

同步解析短文档

适合图片和短 PDF。会话或 API Key 均可调用。

curl -X POST http://localhost:8080/v1/parse \
  -H "Authorization: Bearer <API_KEY>" \
  -F "file=@resume.pdf"
03 · ASYNC

异步处理大文档

创建任务后轮询状态，成功后读取结果。

curl -X POST http://localhost:8080/v1/jobs \
  -H "Authorization: Bearer <API_KEY>" \
  -F "file=@scan.pdf"
04 · PIPELINE

格式解析管线

DOC / DOCXDOC 经 LibreOffice 转换后进入 Mammoth + 语义 HTML
图片RapidOCR
文本型 PDFOpenDataLoader + 0 页 OCR
扫描 PDFOpenDataLoader + 全页 OCR
混合 PDFOpenDataLoader + 部分页 OCR
05 · ERRORS

追踪失败请求

业务错误包含稳定错误码和 request_id，便于调用方重试和服务端定位。

{ "error": { "code": "FILE_TOO_LARGE", "request_id": "req_..." } }
