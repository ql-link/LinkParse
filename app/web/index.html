GUIDE

使用指南

从服务检查到异步任务的完整接入路径。

打开 API 文档
01 · HEALTH

先检查服务状态

健康接口不需要 API Key，会返回三个核心解析组件的可用状态。

curl http://localhost:8080/health
02 · SYNC

同步解析短文档

适合图片和短 PDF。默认自动选择引擎并返回 Text 与 JSON。

curl -X POST http://localhost:8080/v1/parse \
  -H "Authorization: Bearer <API_KEY>" \
  -F "file=@resume.pdf" \
  -F "engine=auto" \
  -F "output_formats=text,json,markdown"
03 · ASYNC

异步处理大文档

创建任务后轮询状态，成功后读取结果。状态包括 queued、processing、succeeded、failed 和 expired。

curl -X POST http://localhost:8080/v1/jobs \
  -H "Authorization: Bearer <API_KEY>" \
  -F "file=@scan.pdf"
04 · ROUTING

Auto 路由策略

图片RapidOCR
文本型 PDFOpenDataLoader
扫描 PDFRapidOCR
混合 PDF结构解析 + OCR 补齐

ocr=always 强制 OCR，ocr=never 禁止 OCR。

05 · ERRORS

追踪失败请求

业务错误包含稳定错误码和 request_id，便于调用方重试和服务端定位。

{
  "error": {
    "code": "FILE_TOO_LARGE",
    "message": "Uploaded file exceeds 50MB limit",
    "request_id": "req_..."
  }
}
